How it works

Three steps, then it gets out of your way.

  1. 1

    Work normally

    It sits in your menu bar or system tray and counts down. Closing the settings window does not quit it.

  2. 2

    Take the break

    Your screen is covered for as long as you chose. There is no Skip button — the point is the habit.

  3. 3

    Back to it

    The break disappears on its own and the next interval starts. No streaks, no score, nothing to keep up with.

Esc is the way out

No Skip button, but never a trap. Esc ends a break immediately and starts a fresh interval, so it will not spring straight back.

Pausing does not owe you

Resume always begins a whole new interval. Time spent paused is not counted, so you never get a break the second you come back.

Sleep through it and nothing piles up

Close the lid past several scheduled breaks and you get exactly one when you wake, not a backlog.

A corrupt settings file will not stop it

Settings are plain JSON you can edit. Break one field and only that field resets — the app repairs it rather than starting over.

What it looks like

Small, quiet, and over in a minute.

It stays on your machine

Not a promise in a privacy policy — there is no code that could send anything anywhere.

  • No account, no sign-in, nothing to create.
  • No telemetry, no analytics, no crash reporting.
  • No network requests at all, not even a version check.
  • No database. Settings are one small JSON file you own.

The app's entire permission set, from capabilities/default.json: 

"permissions": [
  "core:event:allow-listen",
  "core:event:allow-unlisten"
]

That is it. No filesystem access for the interface, no shell, no HTTP, and not a single plugin.

Get it

There are no packaged releases yet. For now you build it yourself — it takes one command once the toolchain is set up. 

git clone https://github.com/shivpsingh/screenbreak.git
cd screenbreak
pnpm install
pnpm tauri build

Needs Node 18+ and a Rust toolchain, plus a few system packages on Linux. The development guide has the details.

  • macOS .app and .dmg · unsigned for now
  • Windows .msi and .exe · unsigned for now
  • Linux .deb, .rpm, AppImage

Because the builds are unsigned, macOS and Windows will warn you the first time. On macOS, right-click the app and choose Open. Removing those warnings needs paid certificates — the distribution notes explain what that involves.
